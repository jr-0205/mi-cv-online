PERFIL

Software que se puede probar, desplegar y mantener.

Soy desarrollador de software con formación en Ingeniería en Sistemas Computacionales y trabajo público verificable en 18 repositorios. Construyo APIs REST con Express, Prisma y MySQL, aplicaciones de escritorio en .NET con WPF y WebView2, interfaces con React, apps móviles con Flutter y mods de cliente en Java con Fabric.

Trabajo con arquitectura por capas, separando lógica de negocio, persistencia y presentación. Valido entradas y estados antes de ejecutar cambios, escribo pruebas automatizadas, documento contratos e instalo CI/CD con GitHub Actions para que cada cambio se compile y verifique de forma repetible. Trabajo en equipo usando Git con revisión de cambios y convenciones de nombres consistentes.

Me interesa que una solución funcione sin depender de explicaciones externas: despliegue reproducible, reversibilidad en operaciones destructivas y documentación que describa límites y compatibilidad, no solo el caso feliz.
